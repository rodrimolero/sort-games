# Videogames Dataset in C

Based of a summarized dataset about video games released in 2008 this program will sort the games in the file by review score and print them in the order in a file 

## Features
- Videogames names, genre, review score, price, console, and rating
- Promts the user for a file with the videogames data
- Sorts the games based on their review score
- Display all videogames in sorted order

## Technologies
- C programming language
- Standard I/O
- Structs, functions and files
